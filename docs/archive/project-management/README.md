# Historical project-management sources

This directory preserves completed task, plan, and handoff files for `react-leaflet-explorer`. Active generic package work belongs in this repository's GitHub Issues.

The archive is read-only. Do not update status in these files.

- `tasks/` contains six historical package tasks.
- `plans/` contains seven completed motion plans and their former index.
- `handoff/` contains three release and review records.

The package work represented here is implemented and published through version `0.2.2`. Remaining physical product review belongs to [the Hysvær project](https://github.com/johan-eilertsen/hysvaer/issues/3), not to a synthetic package milestone.

`SHA256SUMS` covers all 17 moved sources.
