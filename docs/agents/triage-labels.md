# Triage-roller

Dette repoet bruker [den felles koblingen mellom Matts fem roller og native GitHub-felt](https://github.com/johan-eilertsen/project-control/blob/main/config/github/matt-triage.md).
Rollene `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` og `wontfix` er betydninger, ikke nye etiketter.

Les koblingen før triage og bruk [repoets issue-kontrakt](issue-tracker.md). En vurdering endrer ingen felt uten myndighet. Kontroller levende status og ansvar før oppdatering; `Parked` betyr utsatt, ikke avvist.
